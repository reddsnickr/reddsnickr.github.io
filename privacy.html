Privacy Policy

Last updated: November 2, 2026

This policy describes how the reddsnickr application ("the app") handles data. The app is a private publishing tool operated by the owner of the Redd Snickr YouTube channel and is used only with the owner's own Google account.

Data the app accesses

With the owner's consent through Google OAuth, the app uses the YouTube Data API with these permissions:

  • youtube.upload – to upload the channel's own videos;
  • youtube – to read the channel's own video list, in order to avoid uploading the same video twice.

The app does not access any other Google user data and does not access any data of other users.

How data is used and stored

  • OAuth tokens are stored only on the owner's private server and are used solely to upload and manage the owner's own videos.
  • No data is sold, shared with, or transferred to third parties.
  • No data is used for advertising or for training machine-learning models.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions. Stored tokens are deleted from the server on request.
